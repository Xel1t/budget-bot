# 💰 Семейный Бюджет-Бот

Telegram-бот для совместного ведения бюджета.

---

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/add` | Добавить трату (с выбором категории) |
| `/overview` | Остаток на месяц + накопления |
| `/stats` | Статистика трат по категориям |
| `/savings` | Все кошельки с накоплениями |
| `/wallet` | Пополнить / снять / обновить кошелёк |
| `/debt` | Записать долг |
| `/debts` | Список открытых долгов |
| `/settle <номер>` | Закрыть долг |
| `/history` | Последние 10 трат |
| `/fixed` | Фиксированные расходы |

## 🚀 Запуск за 15 минут

### Шаг 1 — Создать бота в Telegram

1. Открой Telegram, найди `@BotFather`
2. Напиши `/newbot`
3. Придумай имя боту (например: `Family Budget Bot`)
4. Придумай username (например: `tim_family_budget_bot`)
5. Скопируй **токен** — он выглядит так: `1234567890:ABCdef...`

### Шаг 2 — Получить бесплатный API ключ для курсов валют

1. Зайди на https://www.exchangerate-api.com
2. Зарегистрируйся (бесплатно, 1500 запросов/месяц)
3. Скопируй API ключ

> Если не хочешь регистрироваться — оставь `EXCHANGE_API_KEY` пустым.
> Бот будет использовать курс 0.92 как запасной.

### Шаг 3 — Загрузить код на GitHub

1. Зайди на https://github.com и создай новый репозиторий (например `budget-bot`)
2. Загрузи все файлы из этой папки

### Шаг 4 — Задеплоить на Railway (бесплатно)

1. Зайди на https://railway.app
2. Нажми **"New Project"** → **"Deploy from GitHub"**
3. Выбери свой репозиторий `budget-bot`
4. Перейди в **Variables** и добавь:
   ```
   BOT_TOKEN = твой_токен_от_BotFather
   USER1 = твой_username_без_собачки
   USER2 = username_девушки_без_собачки
   EXCHANGE_API_KEY = твой_ключ (или оставь пустым)
   ```
5. Railway автоматически запустит бота — готово! ✅

## 💡 Как пользоваться

### Добавить трату
```
/add
→ выбери категорию кнопкой
→ введи сумму: 350  (или  40 USD  для автоконвертации)
→ добавь комментарий или напиши -
```

### Посмотреть остаток
```
/overview
```
Покажет: зарплата → фикс. расходы → потрачено → **сколько осталось и на сколько в день**

### Обновить накопления
```
/wallet
→ выбери кошелёк
→ пополнить / снять / установить сумму
```

### Записать долг
```
/debt
→ введи имя (например: Маша или @masha)
→ введи сумму
→ выбери валюту
→ добавь комментарий
```

### Закрыть долг
```
/debts  — посмотреть список с номерами
/settle 3  — закрыть долг #3
```

## ⚙️ Настройки (в коде bot.py)

```python
INCOME_USD = 3700.0       # Зарплата на руки
SAVINGS_USD = 500.0       # Автосбережения (не входят в бюджет)

FIXED_EXPENSES = [        # Фиксированные расходы
    ("Аренда квартиры",  1280.0),
    ("Интернет",           26.0),
    ("Свет",              100.0),
    ("Вода",               30.0),
    ("Спортзал",           35.0),
]
```

Чтобы изменить — просто отредактируй эти строки и перезапусти бота.

## 📦 Стоимость хостинга

Railway даёт $5 кредитов бесплатно при регистрации.
Маленький бот потребляет ~$0.50–1/месяц → хватит на 5–10 месяцев.
После — можно добавить карту, стоимость остаётся ~$1/мес.
